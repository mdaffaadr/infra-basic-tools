# Infra Basic Tools
Collection of simple infrastructure, monitoring, networking, and automation scripts built with Python and Termux.

## Features

### Monitoring
- HTTP status checker
- Logging system
- Retry mechanism

### Networking
- TCP port connectivity checker

### API
- JSON API response checker

### System
- Linux system information tool

## Environment
- Python
- Termux
- Linux command line

## Run
```bash
python check.py
python port.py
python logger_check.py
python retry_check.py
python api_check.py
python sysinfo.py
